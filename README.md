# Steel Ball Run

A Steel Ball Run (JoJo Part 7) Stand game for Roblox, written in Luau and laid out for [Rojo](https://rojo.space) 7.

Ride a horse from the San Diego beach to New York across nine stages, awaken a Stand, fight outlaws and Stand-user bosses, race rival riders and duel other players in a ranked arena. The whole world is generated by code when the server starts. The place uses no uploaded assets: every model is built from Parts and Motor6Ds, and the only sounds and textures are the ones bundled with the Roblox client (`rbxasset://`).

## Getting it into Studio

### With Rojo (recommended)

1. Install Rojo 7 and the Rojo Studio plugin.
2. From the repository root, either serve the project live:

   ```
   rojo serve
   ```

   then open an empty Baseplate in Studio and press **Connect** in the Rojo plugin, or build a place file:

   ```
   rojo build -o SteelBallRun.rbxlx
   ```

   and open `SteelBallRun.rbxlx` in Studio.
3. If your template came with a Baseplate part or a SpawnLocation, delete them. The server builds the ground and places every character itself.
4. Press Play. The loading screen shows the map build progress and lifts once your character spawns.

`default.project.json` also sets the place properties the game depends on:

| Service | Property | Value |
| --- | --- | --- |
| Players | CharacterAutoLoads | false (the server spawns characters once the map is ready) |
| Workspace | StreamingEnabled | true, min radius 128, target radius 768 |
| Workspace | Gravity | 196.2 |
| Lighting | Technology | Future |

### Without Rojo

Every top-level folder in this repository is named after the Studio service it belongs in, so the repository mirrors the Explorer:

| Repository folder | Goes in Studio under |
| --- | --- |
| `ReplicatedFirst` | ReplicatedFirst |
| `ReplicatedStorage` | ReplicatedStorage |
| `ServerScriptService` | ServerScriptService |
| `StarterPlayer/StarterPlayerScripts` | StarterPlayer > StarterPlayerScripts |

Inside those, recreate each subfolder as a Folder with the same name (for example ReplicatedStorage > Shared, or StarterPlayerScripts > UI > Tabs). Each `.luau` file becomes a script named after the file without its suffix, with the file's contents pasted into it:

| File ends in | Create a | Example |
| --- | --- | --- |
| `.server.luau` | Script | `ServerScriptService/Main.server.luau` becomes a Script named Main |
| `.client.luau` | LocalScript | `StarterPlayer/StarterPlayerScripts/Client.client.luau` becomes a LocalScript named Client |
| `.luau` | ModuleScript | `ReplicatedStorage/Shared/Config.luau` becomes a ModuleScript named Config |

Then set the place properties from the table above yourself.

### Saving progress

Profiles are stored with DataStoreService. To test saving in Studio, publish the place, open **Game Settings > Security** and turn on **Enable Studio Access to API Services**. Without it the server logs a warning and keeps profiles in memory, so everything works but nothing is saved.

## Controls

### On foot

| Action | Keyboard and mouse | Gamepad |
| --- | --- | --- |
| Punch | Left click | R2 |
| Stand moves 1 to 5 | Z, X, C, V, B | D-pad left, up, right, Y, R3 |
| Summon or dismiss Stand | Q | L1 |
| Block (hold) | F | L2 |
| Dodge | Left Ctrl | R1 |
| Whistle for your horse | H | D-pad down |
| Menu | M or Tab | Select |
| Toggle duels (PvP) | P | |
| Use a prompt | The key shown on the tag, or click the tag | The button shown on the tag |

Touch players get on-screen buttons for the same actions and can tap the hotbar slots and prompt tags.

### Riding

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Mount | E near your horse | X |
| Steer | W A S D | Left stick |
| Jump | Space | A |
| Gallop (hold, uses stamina) | Left Shift | L3 |
| Change cruising gait (walk, trot, canter) | R | Y |
| Get off | G, or click the Get off tag | B |

### Taming a wild horse

Hold E on a wild horse to start. A needle swings across a bar; press E, Space or click while it is inside the calm band. Land enough rounds and the horse joins your stable, where you can rename it, heal it and dress it in tack.

## How the game is put together

Every system lives in its own module. The server owns all game state and validates every request. The client renders, animates and sends input.

### Server (`ServerScriptService`)

- `Main.server.luau` starts each service in order, builds the world, then begins spawning players and NPCs.
- `Services/Net` wraps the remotes with rate limits, argument checks and typed request and action handlers.
- `Services/DataService` loads and saves profiles with retries and backoff, a session lock so two servers never write the same profile, autosave, and a save on leave and on shutdown.
- `Services/CharacterService` spawns characters at the right stage, applies spawn protection and handles death.
- `Services/CombatService`, `Combatants`, `Hitbox`, `Moves` and `Projectiles` run combat: server-side hitboxes, block, dodge, stagger, combo limits, Stand durability and Stand break, status effects and every Stand move.
- `Services/StandService` handles the Arrow and Rokakaka, summoning, the Stand following its user, evolution and Stand storage.
- `Services/LevelService` and `MasteryService` handle levels, stat points and per-move mastery with diminishing returns for farming the same target.
- `Services/SkinService` and `ShopService` sell Stand skins and items.
- `Services/HorseService` runs horse physics, mounting, stamina, health, XP, buying, taming, naming, tack cosmetics, the whistle and wild horses.
- `Services/NPCService` and `NPCBrain` spawn outlaws, riders, townsfolk and the stage bosses, each boss with several phases and lines of dialogue.
- `Services/QuestService` runs daily quests and the quest board in each town.
- `Services/RaceService` runs the Steel Ball Run itself: lobby, countdown, checkpoints, rivals with rubber banding, standings and prizes.
- `Services/PvPService` handles the duel toggle, safe zones, the ranked 1v1 arena with its queue and rating, the kill feed and the leaderboards.
- `World/*` builds the map from a seed: terrain, the trail, towns, buildings, nature, props, landmarks, boss arenas and the atmosphere for each stage.

### Shared (`ReplicatedStorage`)

- `Shared/Config` holds the tuning numbers for every system, including the map seed. Change balance here.
- `Shared/Route`, `HeightField`, `Zones` and `Layout` describe the world so the server and client agree on stages, towns and ground height.
- `Shared/StandData`, `HorseData`, `NPCData`, `ItemData`, `QuestData`, `SkinData` and `Progression` are the game data tables.
- `Shared/HorseMotor` is the horse movement model, shared so the client can predict its own horse.
- `Shared/Style` is the UI palette and fonts. `Shared/Types`, `Signal`, `Util` and `Remotes` are support code.
- `Builders/*` construct horses, Stands and character rigs from Parts and Motor6Ds.

### Client (`StarterPlayerScripts`)

- `Client.client.luau` starts each controller and UI module. One failing module is reported and the rest still run.
- `Controllers/HorseController` drives your own horse with prediction. `InputController` handles combat and utility input.
- `Controllers/HorseAnimator` animates every horse procedurally: walk, trot, canter and gallop gaits, head bob, tail sway, breathing, ear flicks, rearing, landing squash, dust and hoof sounds. It also poses riders in the saddle.
- `Controllers/StandAnimator` and `RigAnimator` pose Stands, NPCs and punches. `Joints` holds the shared Motor6D helpers.
- `Controllers/FXController` draws every combat effect, projectile and status. `CameraController` adds speed-based field of view and camera shake. `AmbienceController` blends each stage's atmosphere and runs the wind, tumbleweeds, windmills and town music.
- `UI/Kit` is the small component library every screen is built from. `Hud`, `Feed`, `HorseHud`, `RaceHud`, `Map` (route bar and minimap), `TameGame`, `Prompts` and `Menu` with its `Tabs` are the screens.

The interface follows a flat Western poster look: parchment and leather colors, dark ink text, Merriweather headings, Source Sans Pro body text and Roboto Mono numbers. Panels slide rather than fade, and there are no gradients, icons or blur.

## Notes

- Every script is `--!strict` Luau and passes `luau-lsp analyze` with the Roblox type definitions and a Rojo sourcemap.
- Changing `Config.Data.StoreName` starts everyone with fresh profiles, so leave it alone once the game is live.
